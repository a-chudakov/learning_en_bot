# 🤖 Learning English Bot

Telegram-бот для изучения английского языка с интерактивной тренировкой и алгоритмом интервального повторения (SRS).

## ✨ Возможности

- 📝 Добавление слов с транскрипцией и темами
- 🎯 Интерактивная тренировка (4 режима)
- 🔔 Автоматические напоминания в установленное время
- 📊 Статистика обучения
- 🧠 Алгоритм интервального повторения (SRS)
- 📄 Пагинация списков слов

## 🚀 Быстрый старт (локально)

### Требования

- Python 3.11 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

1. **Клонируй репозиторий:**
   ```bash
   git clone <your-repo-url>
   cd learning_en_bot
   ```

2. **Установи зависимости (используя uv):**
   ```bash
   # Если у тебя нет uv
   curl -LsSf https://astral.sh/uv/install.sh | sh
   
   # Установка зависимостей
   uv sync
   ```

   **Или используя pip:**
   ```bash
   pip install -e .
   ```

3. **Создай файл `.env` в корне проекта:**
   ```bash
   cp .env.example .env
   # Или создай вручную
   ```

4. **Отредактируй `.env` файл:**
   ```env
   TELEGRAM_TOKEN=твой_токен_бота_от_BotFather
   DATABASE_PATH=./data/bot.db
   BOT_USERNAME=learning_en_bot
   LOG_LEVEL=INFO
   TIMEZONE=Europe/Moscow
   ```

5. **Запусти бота:**
   ```bash
   # С uv
   uv run python -m src.learning_en_bot.main
   
   # Или с pip
   python -m src.learning_en_bot.main
   ```

### Структура проекта

```
learning_en_bot/

```

## 📖 Использование

1. Найди своего бота в Telegram
2. Нажми `/start` для начала работы
3. Добавь слова: `cat - кот - [kæt] #животные`
4. Начни тренировку через кнопку 🎯 Тренировка
5. Настрой напоминания в ⚙️ Настройки

## 📝 Переменные окружения

| Переменная | Обязательная | По умолчанию | Описание |
|-----------|--------------|--------------|----------|
| `TELEGRAM_TOKEN` | ✅ Да | - | Токен бота от @BotFather |
| `DATABASE_PATH` | ❌ Нет | `./data/bot.db` | Путь к базе данных |
| `BOT_USERNAME` | ❌ Нет | `learning_en_bot` | Имя бота |
| `LOG_LEVEL` | ❌ Нет | `INFO` | Уровень логирования |
| `TIMEZONE` | ❌ Нет | `UTC` | Часовой пояс |

## 🐛 Решение проблем

### Бот не отвечает

- Проверь, что `TELEGRAM_TOKEN` правильный
- Убедись, что бот запущен (нет ошибок в логах)
- Проверь подключение к интернету

### Ошибки с базой данных

- Убедись, что директория `data/` существует и доступна для записи
- Проверь права доступа к файлу базы данных

### Проблемы с зависимостями

- Обнови Python до версии 3.11+
- Переустанови зависимости: `uv sync` или `pip install -e .`
